```
[1] 用户                            [2] 上传/文字             [3] 风格来源
  ┌─────────┐   ──创建项目──►   ┌──────────────────┐    ┌──────────────┐
  │ 浏览器  │                    │  UploadService    │    │  preset /    │
  │  SPA    │                    │  (Sharp + Storage)│    │  custom /    │
  └─────────┘                    └──────────────────┘    │  reference   │
                                                        └──────┬───────┘
                                                               │
                                                               ▼
[4] 风格画像 ◄─────confirm──────┐
  ┌──────────────────┐          │
  │  StyleProfile    │ ◄────────┘
  │  (theme /        │
  │   palette /      │ ◄──── ReferenceStyleService
  │   pace / bgm /   │      (yt-dlp + FFmpeg + Py 容器)
  │   caption /      │
  │   motion)        │
  └────────┬─────────┘
           │ confirmed
           ▼
[5] CreativePlan (planner capability / RulePlanner)
  ┌──────────────────────────────────────────────────────────────┐
  │  creative_intent   (theme + 4 段叙事弧 + mood)                │
  │  emotional_curve   (≥4 点: valence/arousal + visual/bgm/sub) │
  │  bgm_rationale     (selected_track_id / bpm / energy / reason)│
  │  bookend           (opening_scene_id == closing_scene_id)     │
  │  directions[]      (2–3 个;用户选 1)                          │
  │  scene_plan        (展开后完整 scene plan)                    │
  │  status: draft → proposed → confirmed →                      │
  │          applied_to_storyboard → stale (输入变化即 stale)     │
  └──────────────────────────────────────────────────────────────┘
           │ confirmed + input_digest
           ▼
[6] Storyboard (draft + version CAS)
  ┌──────────────────────────────────────────────────────────────┐
  │  EditorSpecValidator: §9C 全部契约                           │
  │  (时间线 / 安全区 / 字幕 / BGM / 动效白名单 / 转场白名单)    │
  └──────────────────────────────────────────────────────────────┘
           │ confirmed + canonical digest
           ▼
[7] Render (RenderPipeline, RenderQueue)
  ┌──────────────────────────────────────────────────────────────┐
  │  冻结 render_input.json (不可变):                            │
  │    - 文字 / 已接受提示词提案                                  │
  │    - StyleProfile + CreativePlan (direction + scene_plan)    │
  │    - ProjectSettings + 4 capability 状态                     │
  │    - 资产摘要 (SHA-256) + BGM/字体 (SHA-256 + LICENSES 摘要) │
  │    - 工具 / container 版本 + feedback 来源                   │
  │  ─ FFmpeg: 1080×1920 / H.264 + AAC / yuv420p / 30 fps      │
  │  ─ ASS 字幕 (底部安全区 12%)                                 │
  │  ─ BGM 1.0s 淡入淡出 / -16 LUFS                              │
  │  ─ ffprobe 验证 (误差 ≤ 0.5s)                                │
  └──────────────────────────────────────────────────────────────┘
           │ completed
           ▼
[8] 预览反馈循环
  ┌──────────────────────────────────────────────────────────────┐
  │  feedback_parser (AI / 有限意图词典)                          │
  │  → 白名单 changes[] + confidence                              │
  │  → unsupported_text[] (用户用结构化控件澄清)                  │
  │  → 接受 → 新 draft + parent_revision_id → new revision       │
  └──────────────────────────────────────────────────────────────┘
           │ is_final
           ▼
[9] 下载 MP4 (Range)  ──►  ❌ 不做分享 (v0.1)
```

## 4. 关键守门规则（贯穿整个架构）

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  必须由显式"接受"操作改变状态;前端按钮 + 服务端摘要双重校验                  │
│  ─ planner:          方向选择 + 方案确认 (direction → confirm)              │
│  ─ prompt_optimizer: 提案仅 proposed;接受必须提交 proposed_digest          │
│  ─ caption_effects:  输出经 Zod + 白名单 + §9C 三重校验;进入分镜确认       │
│  ─ feedback_parser:  接受前不可改 draft;parent_revision_id 锁定             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│  Stale 规则 (CreativePlan / Storyboard)                                     │
│  输入变化 ─► 立即 stale (禁止渲染) ─► 必须重新生成 + 重新确认              │
│  触发条件: 素材 / 文字 / 风格 / AI 开关 / feedback 应用 /                  │
│           Storyboard 编辑 / CreativePlan 编辑 / 确认门禁条件变化           │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│  Key / AccessKey 隔离                                                       │
│  GET / capabilities / 日志 → 仅 PublicProviderProfile / PublicStorageConfig│
│  Adapter 内部          → 仅 InternalProviderCredentials /                  │
│                            InternalOSSCredentials (不可序列化)              │
│  两种类型不可复用;0700 / 0600 文件权限;CSRF / Origin 校验;备份默认排除      │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│  渲染输入冻结 (render_input.json 不可变)                                     │
│  retry 在项目锁内逐字节复制 render_input.json;                              │
│  worker 不读取当前 draft / settings / AI / 工具;                            │
│  工具 / provider 升级不改变历史输出。                                       │
└─────────────────────────────────────────────────────────────────────────────┘
```
